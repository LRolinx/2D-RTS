# 2D RTS

基于 Vue 3、TypeScript、Vite 6 和 PixiJS 的可运行 2D RTS，固定使用 pnpm 管理依赖。Vue 管理应用生命周期与加载错误界面，PixiJS 负责战场渲染、单位、建筑、寻路、战斗、经济、混合战略 AI 和交互。

## 运行

```bash
pnpm install
pnpm dev
```

默认地址：`http://127.0.0.1:5173/`

## 构建与检查

```bash
pnpm exec vue-tsc --noEmit
pnpm test
pnpm build
```

`pnpm test` 验证战略 AI 的扩张、防守、恢复和进攻决策；`pnpm build` 会先执行类型检查，再生成 Vite 生产构建。

生产构建会将 PixiJS 单独拆分为缓存友好的异步依赖包，避免游戏入口包过大；构建输出中的各个 chunk 均应低于配置的体积告警阈值。

依赖安全检查：

```bash
pnpm install --frozen-lockfile
pnpm audit --prod
```

`package.json` 中的 pnpm overrides 用于锁定传递依赖的已修复版本；更新依赖后应重新运行审计和构建。

## 已实现玩法

- 左键点选单位或地块，左键拖拽框选编队。
- 右键给选中单位下达编队移动命令；支持地形代价、动态寻路预留、单位避让和碰撞修正。
- `Ctrl` + `1`–`9` 保存编队，按数字键快速重新选中；点击小地图可快速跳转镜头。
- 初始镜头自动聚焦玩家基地，`Home` 可重新聚焦；鼠标滚轮缩放，鼠标中键或 `Alt` + 拖拽移动视角。
- 玩家和敌方拥有基地、工程师、混合兵种、资源点和可建造防御体系。
- 水域不是装饰：`[` 建造船厂，`K/L/,/.` 分别生产潜艇、战列舰、导弹舰和防空舰；船厂只能部署在有陆地连接的水域。
- 单位会自动索敌、转向、开火、发射子弹/炮弹/导弹/炸弹/光束，并处理范围伤害、空地目标限制、命中反馈和残骸。
- 资源点可被采集器占领并持续产出资源；资源耗尽后会停止产出。
- 基地、工厂和空军基地支持生产队列；工程师支持建造和维修。
- 炮塔、雷达、维修站、采集器、工厂和空军基地均可建造；右侧命令面板支持鼠标点击，快捷键同样可用。
- 敌方使用战略 AI 管理经济、生产、扩张、防御和进攻；单位配置从随附 INI 资源解析。
- 敌方 AI 使用“规则规划 + NEAT 输出偏置”的混合决策，按开局、扩张、科技、防守、恢复和进攻阶段动态切换目标、生产和撤退策略；玩家单位不会被战略 AI 自动接管。
- 战局结束会停留在胜负面板，点击“重新开始”或按 `Enter` / `R` 开始新战局，不再静默自动重置。
- `Space` 暂停/继续，`R` 重置战场，`Enter` 在战局结束后重开，`1` / `2` / `3` 切换模拟速度，`+` / `-` 微调速度。
- 战场重置和回合循环会清理旧的单位、地形和特效显示对象，避免重复部署造成资源累积。

## 快捷键

生产快捷键从 `M`（工程师）、`Q`（侦察车）、`W`（坦克）开始，右侧面板会显示全部兵种、建筑和当前资源价格；`K/L/,/.` 是海军生产。生产和建造按钮可以直接点击；建造前需要选中工程师、再选中合法地块。

## 压测

访问以下地址可验证不同地图与质量场景：

- `http://127.0.0.1:5173/?map=frontier`：边境地图（默认）。
- `http://127.0.0.1:5173/?map=highlands`：高地地图，山地和高差更多。
- `http://127.0.0.1:5173/?map=archipelago`：群岛地图，水域和岛屿更多。
- `http://127.0.0.1:5173/?qa=stress-1000`：1000 单位同屏压测场景。
- `http://127.0.0.1:5173/?qa=match-end`：胜负面板和重新开始按钮回归场景。

压测模式会降低地图、UI 和小地图刷新频率以保持交互稳定。

主战场运行器位于 `src/examples/Rts/pixiRts.ts`，应用入口和加载生命周期位于 `src/App.vue`。
